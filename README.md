# Fox Run Labs — Ryan Clarke

A buildless, responsive software and embedded systems portfolio. The site is served from the root of the `main` branch at https://foxrunlabs.github.io/. All internal asset and page links are relative.

## Pages

- `index.html`: selected work, engineering approach, background, and public profile links
- `myqth.html`: iOS location utility case study
- `qbplay.html`: macOS interpreter and audio synthesis case study
- `chip8-stm32.html`: embedded C++ case study and original hardware demo

## Evidence and media

Project descriptions are grounded in the public Fox Run Labs repository READMEs and selectively reviewed source. Screenshots are taken from the MyQTH and QBPlay repositories. The CHIP-8 video is converted from the original repository demonstration to a compressed MP4 for browser playback. WebP images are resized exports of source media. No builds, automated app tests, or new hardware tests were performed for this website update.

Additional repository links include v65C02, PCXPreview, PCD8544, and CTF writeups. Their presence does not imply current reproducibility or production readiness. Direct contact details and resume are omitted until supplied.

## Maintenance

Edit static HTML and `style.css`. Optional Google Fonts have system fallbacks. No runtime dependencies, application backend, or client-side JavaScript. Run an HTML asset/link check before deployment.
